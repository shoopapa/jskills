# Reference library

These references provide lenses, not templates. The application notes below are design interpretations. Do not claim that a brand publishes these exact rules or reproduce proprietary work. When current visual specifics matter, inspect the live reference before making claims.

## Linear: calm through consistency
[Behind the latest design refresh](https://linear.app/now/behind-the-latest-design-refresh)

The team's discussion of predictable action placement and coherent interface treatment is useful for working tools. Apply it by keeping actions in stable locations and using a disciplined component vocabulary. Avoid adopting a dark palette or tiny typography merely because it seems 'Linear-like'.

## Apple: legibility and clear interaction
[Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)
[Typography](https://developer.apple.com/design/human-interface-guidelines/typography)

Use the guidelines as a reference for accessible, readable interfaces and hierarchy. Translate the principles to the actual platform instead of making a web tool imitate an Apple product launch page. Whitespace should separate tasks, not make them difficult to reach.

## Stripe: product specificity
[Stripe product site](https://stripe.com/)

Study how product examples and concrete business actions can explain an otherwise abstract service. For a tool, let its actual output demonstrate value. This is an interpretive reference, not a claim about Stripe's internal design system. Do not copy its gradients, illustrations, or branding by default.

## Swiss typography: organization and precision
[Swiss National Library: The International style, 1950–1970](https://www.nb.admin.ch/en/the-international-style-1950-1970)

The library identifies typographic grids, sans serif type, and rigorous composition. Use a grid to create intentional alignment and hierarchy, with enough flexibility for different content and devices. A useful grid is not an excuse for uniform cards or rigidly centered pages.

## Bauhaus / New Typography: form serving communication
[MoMA: The New Typography](https://www.moma.org/calendar/exhibitions/1013)
[Cooper Hewitt: Bauhaus Typography at 100](https://www.cooperhewitt.org/2022/04/05/bauhaus-typography-at-100/)

Draw on functional composition, typographic experimentation, and deliberate geometric relationships. Use the idea of reduction to essentials; do not apply red circles, yellow triangles, and oversized type as an automatic costume.

## Choosing a reference
For a data-heavy tool, start with Linear's consistency and Swiss alignment. For a customer-facing artifact, combine product specificity with one expressive typographic choice. For a report, prioritize Swiss hierarchy and legibility. For a deck, use one clear assertion and supporting evidence per visual unit. The user's brand and audience outrank these suggestions.
