# Techniques by intended effect

Choose the effect first. These are options, not a mandatory style system.

## Make the main point unmistakable
- **Contrast in scale:** a compact section label against one decisive headline. Keep body copy comfortably readable; avoid giant headings that bury the task below the fold.
- **Asymmetric balance:** a narrow control column and a wider result canvas, or an editorial headline paired with real output. Stack in task order on mobile.
- **Direct annotation:** label the interesting point on a chart or document instead of requiring a legend lookup. Avoid clutter if many series compete.

## Improve scan speed
- **Shared alignment lines:** align headings, inputs, rules, and values to a small number of axes. Use whitespace to group related content.
- **Tabular numerals and consistent units:** align comparable values and use one formatting convention per measure. Do not hide meaningful precision.
- **Ruled sections:** separate related groups with a thin rule and spacing instead of putting every group inside another card.
- **Information-bearing labels:** replace vague 'Overview' and 'Insights' labels with the action or result: 'Crew still awaiting training' or 'Print your poster'.

## Make a tool feel tangible
- **Real output as preview:** show an actual poster, export, or report using believable sample content. Clearly label samples and never let sample output masquerade as the user's generated result.
- **Document grammar:** use margins, a production/title/date masthead, measured rules, and a legible footer for a printable artifact. Preserve a QR code's quiet zone and scan contrast.
- **Progressive disclosure:** show the next relevant task; reveal details when requested. Keep essential instructions and critical caveats visible.

## Build trust
- **Restrained color roles:** neutral surfaces, one primary action accent, and status colors with text labels. Use a second accent only when it encodes something useful.
- **Evidence near the claim:** source, timeframe, assumptions, and unresolved matches beside the result. Do not dress uncertain estimates as verified facts.
- **Quiet controls:** secondary actions as text or outline buttons, clear primary action, consistent focus styling. Avoid making every control equally bright.

## Add expression without noise
- **One typographic contrast:** use a deliberate weight, size, or family contrast at the editorial focal point. Preserve the established brand and avoid adding fonts without need.
- **Optical spacing:** adjust headline breaks, letter spacing, and icon alignment after rendering. Do not use CSS transforms to paper over a poor layout.
- **One field of color:** use a single section background to establish a transition or emphasize a key result. Do not alternate colorful panels by habit.

## Refine by medium
- **Slides:** one assertion per slide, conclusion-led titles, repeated alignment anchors, evidence cropped to the relevant detail, appendix for density.
- **Spreadsheets:** clear input region, unit-aware number formatting, subtotal hierarchy, minimal gridlines, frozen context, useful print area; never merge cells inside sortable data.
- **Reports/PDFs:** stable folios, consistent captions, controlled widows, deliberate page breaks, tables with repeated headers.
- **Dashboards:** prioritize decisions over vanity totals, align comparisons, separate controls from results, keep context near filters, include meaningful data freshness.
